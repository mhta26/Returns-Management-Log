# التحقق من النسخة المكتبية

## ما نُفذ

- 22 اختبارًا آليًا للمجال والخادم والبيانات: حدود الصلاحية بحسب الإعدادات الحالية، اكتمال البيانات الأولية، PDF عربي بأوراق متعددة عند تجاوز 22 صنفًا، تثبيت البيانات التاريخية، وإعادة المحاولة دون تكرار، وفشل PDF دون استهلاك رقم، و10 طلبات متزامنة من أجهزة/مستخدمين افتراضيين، و4 محاولات متزامنة للطلب نفسه، والنسخ الاحتياطي المتضمن PDF، وصلاحيات المستخدمين، وإسناد أمين الصندوق من حساب الدخول، ومنع الأكواد المكررة، وتغيير كلمة المرور وإلغاء الجلسات، وعدم تعطيل آخر مسؤول، وفحص الكميات والتواريخ، وتسجيل محاولة الطباعة، وتصدير CSV، واستيراد المصنف دون تكرار، واختبار الواجهة عند فقد رد الحفظ بعد اعتماد الخادم دون تكرار السند، واختبار إنتاج نسختين فعليتين من محرك طباعة Qt عند طلب نسختين، ومنع اختيار نتيجة بحث قديمة أثناء تحميل استعلام جديد.
- تشغيل خادم HTTP حقيقي محليًا، وتسجيل الدخول بمطيع، وبحث في البيانات، وفتح الواجهة العربية، وإصدار سند وجلب PDF، وظهور اسم أمين الصندوق في الأرشيف، وفتح عارض PDF الأصلي داخل Qt. التُقطت صور الشاشات من التطبيق الفعلي في docs/.
- مراجعة معاينة PDF بصريًا بالعربية، والشعار، والصفوف والألوان، وحقول المستودع والمحاسب والسائق وأمين الصندوق.
- اختبار تشغيل مستقل للعميل والخادم بـ`--self-test`، دون Excel.

تشغيل الاختبارات من المصدر:

```powershell
python -m pip install -r requirements.txt pytest==8.3.5 pypdf==5.4.0
python -m pytest -q
python launch_server.py --self-test
python launch_client.py --self-test
```

## بناء Windows

ملف `.github/workflows/desktop-windows.yml` يشغّل اختبارات المصدر على Windows، ثم يبني برنامج العميل وبرنامج الخادم بـPyInstaller ويجرب تشغيل EXE الناتجين قبل إنشاء ملف التثبيت والنسخة المحمولة ونشرهما. نتيجة التشغيل في GitHub Actions هي المرجع لنجاح حزمة Windows، وليست مجرد وجود وصف البناء في المستودع.

## ما يتطلب بيئة المستخدم

الطباعة الورقية على تعريفات الطابعات الفعلية، وتوصيل جهازين داخل شبكة المستخدم وفتح المنفذ في جدار الحماية. الاختبارات المتزامنة نفذت على خادم محلي واحد عبر خيوط طلبات متوازية، ولا تمثل اختبارًا لكل جهاز طابعة أو سياسة شبكة. يوضح OPERATIONS.md خطوات قبول على جهازين وخطة الاستعادة.

نجح بناء Windows واختبار تشغيل حزم EXE والخادم والعميل على GitHub Actions بعد إصلاح قفل ملف النسخة الاحتياطية الخاص بـWindows. أُضيف إغلاق صريح لاتصالات SQLite في النسخ الاحتياطي والاستعادة. تظل تجربة الطابعة الورقية داخل شبكة المستخدم اختبار القبول النهائي للأجهزة الفعلية.

أُضيف خط المستخدم IBMPlexSansArabic-Medium.ttf نفسه دون تعديل، وحُمّل داخل Qt للتطبيق وضُمّن في PDF عبر ReportLab. يتحقق اختبار الواجهة من عائلة الخط، ويتحقق اختبار PDF من وجود اسم IBM Plex وخط مضمّن داخل موارد الصفحة. لا يلزم تثبيت الخط على أجهزة المستخدمين.
